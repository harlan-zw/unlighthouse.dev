Lighthouse for your entire site.

Unlighthouse is a free, open-source CLI that runs Google Lighthouse on every page of your site in parallel. It auto-discovers URLs and delivers one unified performance report.

$npx unlighthouse --site example.com

    Integrations

    Snippets from the docs

    Run it where you already work.

    Terminal · no install
    npx unlighthouse --site example.com
    unlighthouse.config.ts
    import { defineUnlighthouseConfig } from 'unlighthouse/config'export default defineUnlighthouseConfig({  site: 'example.com',  debug: true,  scanner: {    device: 'desktop',  },})

    Install globally with npm install -g unlighthouse. Configure with CLI arguments or a config file.

    CI · bash
    npm install -g @unlighthouse/cli puppeteerunlighthouse-ci --site https://staging.example.com --budget 80
    0

    Exit code

    All pages passed.

    1

    Exit code

    Budget failed.

    That is the entire contract. Wire this single command into GitHub Actions, GitLab CI, CircleCI, or any pipeline that runs bash.

    Install
    npm install -D @unlighthouse/nuxt
    nuxt.config.ts
    export default defineNuxtConfig({  modules: [    '@unlighthouse/nuxt',  ],})

    Run your Nuxt app. It gives you the URL of the client; Unlighthouse starts once you visit it.

    Install
    npm install -D @unlighthouse/vite
    vite.config.ts
    import Unlighthouse from '@unlighthouse/vite'import { defineConfig } from 'vite'export default defineConfig({  plugins: [    Unlighthouse({      // config    })  ]})
    Install
    npm install -D @unlighthouse/webpack
    webpack.config.js
    import Unlighthouse from '@unlighthouse/webpack'export default {  // ...  plugins: [    Unlighthouse({      // config    }),  ],}

    Specification

    unlighthouse

    What is in the box.

    MIT

    Free and open source

    S.01
    Parallel scans
    Threaded workers with opportunistic throttling for fast audits.
    S.02
    Auto crawling
    Discovers URLs via robots.txt, sitemap.xml, and internal links.
    S.03
    Smart sampling
    Auto-samples dynamic routes to reduce scan time.
    S.04
    Modern UI
    Search, sort, and re-scan pages in the Vite-powered client.
    S.05
    SEO insights
    Titles, meta descriptions, share images, link analysis.
    S.06
    A11y summary
    Accessibility audit with contrast issue visualization.
    S.07
    Budgets
    One threshold for all pages in CI, or one per category in your config.
    S.08
    Reports
    Interactive dashboard, JSON, CSV, and a static HTML report you can host anywhere.

    Runtime
    Node 22+. Zero config.

01Discover

Find every page. Before you ask.

Point it at a site. Unlighthouse discovers URLs via robots.txt, sitemap.xml, and internal links, then auto-samples dynamic routes to reduce scan time.

  • robots.txt1 sitemap

    Read first. Its sitemap entries tell Unlighthouse where to look.

  • sitemap.xml96 URLs

    Every listed URL joins the queue.

  • internal linksfallback

    No sitemap? It falls back to crawler mode and follows your links from the homepage.

  • /blog/[slug]5 of 41

    Dynamic routes share one template, so a sample stands in for the rest.

02Scan

Light every page. In parallel.

A pool of Chrome workers shares one queue. Each worker takes the next page the moment it is free.

  • Parallel scans

    Threaded workers with opportunistic throttling for fast audits.

  • Real Lighthouse

    Unlighthouse wraps the Lighthouse npm package, so every score is a Lighthouse score.

  • Cached between runs

    Reports restore from cache. Pass --no-cache for a clean run.

04Guard

Hold the line in CI.

Set a budget. Unlighthouse CI scans the whole site and fails the build when any page drops below it. Wire it into GitHub Actions, GitLab CI, CircleCI, or any pipeline that runs bash.

$ npm install -g @unlighthouse/cli puppeteer
$ unlighthouse-ci --site https://staging.example.com --budget 80

“That’s the entire contract.”

From the Unlighthouse CI guide, on exit codes.

exit0

All pages passed.Every category on every page met the budget.

exit1

Budget failed.At least one page fell short. The build stops here.

05Integrate

Wherever you build.

Run Unlighthouse from the CLI, CI, Nuxt, Vite, or Webpack.

Run it once with no install, or install it globally.

# one-time run (no install)npx unlighthouse --site example.com
# global installnpm install -g unlighthouse
CLI guide →

CI environments need Chrome. Install puppeteer alongside the CLI.

npm install -g @unlighthouse/cli puppeteer
unlighthouse-ci --site https://staging.example.com --budget 80
